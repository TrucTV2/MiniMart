# MiniMart POS

A multi-branch Point of Sale system built with **Laravel 12** and **Filament 3**.

![PHP](https://img.shields.io/badge/PHP-8.3-777BB4) ![Laravel](https://img.shields.io/badge/Laravel-12-FF2D20) ![Filament](https://img.shields.io/badge/Filament-3-F59E0B)

## Features

- **Point of Sale:** product search and barcode scanning, category filter, cart, discounts, cash / bank transfer (VietQR) / card payments, change calculation, F9 shortcut, automatic 80mm receipt printing.
- **Products:** SKU, barcode, image, cost and selling price, SEO meta fields, categories, soft delete, bulk publish to website.
- **Inventory:** per-branch stock, multi-line stock import, stock adjustment, full stock movement history, low-stock alerts.
- **Orders:** filter by date / status / cashier / branch, revenue totals, order details, refunds (restock and deduct loyalty points), receipt reprint.
- **Customers:** loyalty points, total spending, VIP filter.
- **Dashboard:** today's revenue vs. yesterday, gross profit, 7/30/90-day revenue chart, best sellers, low-stock list.
- **Role-based access control:** Super Admin, Store Manager, Cashier and Warehouse roles, with data scoped by branch and ownership.
- **Activity log:** tracks changes to prices, products, orders and user accounts.
- **SEO-ready public catalog:** home, product listing, category and product pages with meta tags, Open Graph, JSON-LD structured data, dynamic sitemap and robots.txt.
